Wzory skróconego mnożenia

  • (a + b)² = a² + 2ab + b²
  • (a − b)² = a² − 2ab + b²
  • a² − b² = (a − b)(a + b)
  • (a + b)³ = a³ + 3a²b + 3ab² + b³
  • a³ + b³ = (a + b)(a² − ab + b²)
  • a³ − b³ = (a − b)(a² + ab + b²)

Funkcja kwadratowa

  • f(x) = ax² + bx + c
  • Δ = b² − 4ac
  • x₁,₂ = (−b ± √Δ) / 2a (gdy Δ ≥ 0)
  • Wierzchołek: p = −b / 2a, q = −Δ / 4a
  • Wzory Viète’a: x₁ + x₂ = −b / a, x₁ · x₂ = c / a

Potęgi i logarytmy

  • aᵐ · aⁿ = aᵐ⁺ⁿ, aᵐ / aⁿ = aᵐ⁻ⁿ, (aᵐ)ⁿ = aᵐⁿ
  • a⁻ⁿ = 1 / aⁿ, a⁰ = 1 (dla a ≠ 0)
  • logₐ b = c ⟺ aᶜ = b
  • logₐ (xy) = logₐ x + logₐ y, logₐ (x / y) = logₐ x − logₐ y
  • logₐ xⁿ = n · logₐ x

Trygonometria

  • sin²α + cos²α = 1
  • tg α = sin α / cos α
  • sin 2α = 2 sin α cos α, cos 2α = cos²α − sin²α
  • sin(α ± β) = sin α cos β ± cos α sin β
  • Twierdzenie sinusów: a / sin α = b / sin β = c / sin γ = 2R
  • Twierdzenie cosinusów: c² = a² + b² − 2ab cos γ

Geometria: pola i objętości

  • Twierdzenie Pitagorasa: a² + b² = c²
  • Pole trójkąta: P = ½ · a · h
  • Pole trapezu: P = (a + b) · h / 2
  • Pole koła: P = πr², obwód koła: L = 2πr
  • Sześcian: V = a³, Pc = 6a²
  • Walec: V = πr²h
  • Stożek: V = ⅓πr²h
  • Kula: V = 4/3 · πr³, P = 4πr²

Ciągi

  • Ciąg arytmetyczny: aₙ = a₁ + (n − 1)r, Sₙ = (a₁ + aₙ) / 2 · n
  • Ciąg geometryczny: aₙ = a₁ · qⁿ⁻¹, Sₙ = a₁ · (1 − qⁿ) / (1 − q)

Pochodne i całki

  • (xⁿ)′ = n · xⁿ⁻¹, (sin x)′ = cos x, (cos x)′ = −sin x
  • (eˣ)′ = eˣ, (ln x)′ = 1 / x
  • (f · g)′ = f′g + fg′
  • ∫ xⁿ dx = xⁿ⁺¹ / (n + 1) + C (dla n ≠ −1)

Kombinatoryka i prawdopodobieństwo

  • n! = 1 · 2 · … · n
  • C(n, k) = n! / (k! (n − k)!)
  • P(A) = |A| / |Ω|
  • P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Najczęstsze pytania

Czy mogę wstawić wzór na tablicę zamiast przepisywać?

Tak. W bibliotece matematycznej w Work Docs wybierasz wzór i wstawiasz go na tablicę jednym kliknięciem albo przeciągnięciem.

Czy mogę wpisać własny wzór?

Tak. Edytor wzorów obsługuje ułamki, potęgi, indeksy, pierwiastki, sumy, całki i litery greckie.

Ile wzorów jest w bibliotece?

Ponad 100, podzielone na działy: algebra, logarytmy, ciągi, geometria, geometria analityczna, trygonometria, analiza, kombinatoryka i statystyka, a także podstawowe wzory z fizyki i chemii.

Czy to jest za darmo?

Tak, obecnie wszystkie funkcje Work Docs są darmowe.
